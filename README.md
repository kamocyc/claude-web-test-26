# Smooth World

ゲームシステムは Minecraft ライクだが、**見た目にボクセル感が一切ない完全スムーズな地形**の
ブラウザゲーム。TypeScript + three.js + Vite。

- 無限に広がる地形をシードから生成し、リアルタイムでストリーミング
- **3 種類のブラシ**: 球（穴は常に真円）／**完全に鋭い直方体**／**凸凹をならす**
- 一人称の移動・衝突・ジャンプ・飛行・遊泳
- **バイオーム**（草原・森・砂漠・ツンドラ・山岳）と、**川と湖**、**険しい山と断崖**
- **木**（広葉樹・針葉樹・サボテン）。幹には当たり判定がある
- **村**（家・大広間・小屋・井戸・見張り台と、広場から伸びる土の道）
- **木は伐採できる**（狙って左クリック。切った木は再生成されない）
- **素材は掘った分だけ盛れる**。素材ごとに手持ち量を持ち、ホットバーに表示される
- **土と砂は落ちて安息角の山になる**。積んだ山の下を掘れば崩れてくるし、
  掘った周りの土や砂の地面もその場で崩れる（岩と草はブラシの形のまま固まる）
- **MOB**: 亡霊（夜に湧いて襲ってくる）・鹿（逃げる／皮を落とす）・村人（村を歩く／交換に応じる）
- **クラフト**: マスに並べるのではなく、**材料が揃っていれば押すだけ**で作れる
- **持ち物**: 素材・資源・道具・武器・防具をまとめて持ち、ホットバーへ割り当てて使う
- **体力と戦闘**: 殴られると減り、0 になると最寄りの村で目を覚ます。武器で反撃、防具で軽減
- **建材**（板・レンガ・**透けるガラス**）と**松明**を作って置ける
- **シードを固定できる**（`?seed=` またはタイトル画面の入力欄）
- 海面と水中表現、昼夜サイクル
- 編集差分は IndexedDB に保存され、リロードしても残る

## シードの指定

同じシードなら同じワールドが再現される。

| 指定方法 | 例 |
| --- | --- |
| URL パラメータ | `?seed=4242` / `?seed=demo`（文字列はハッシュされる）/ `?seed=random` |
| タイトル画面 | シード欄に入力して「このシードで開始」 |
| 指定しない | 前回のシード、無ければサンプル用の固定シード `SAMPLE_SEED = 20260823` |

保存領域（IndexedDB）はシードごとに分かれているので、シードを変えても
別のワールドの編集が混ざることはなく、戻れば元の状態が残っている。
「このワールドをリセット」は現在のシードの保存内容だけを消す。

## 素材の手持ち

掘った体積は素材ごとに手持ちへ加算され、盛るとその分だけ減る。

- 掘ると、その場所の素材（プレイヤーが設置したものがあればそれ、無ければ地形本来の
  素材の比率）が、密度場で **固体 → 空** に変わった格子点の数だけ貯まる
- 盛ると、**空 → 固体** に変わった格子点の数だけ減る
- 手持ちが半球ぶんに足りないときはブラシ半径が自動的に縮み、1 未満だと盛れない

掘るのと盛るのがほぼ同じ体積なので交換レートは 1:1 になる。

## 持ち物・クラフト・MOB

### 数え方が 2 種類ある

地形の素材（草・土・岩・砂）と建材（板・レンガ・ガラス）は **体積**で数える。
掘ると「固体 → 空」に変わった格子点の数だけ増え、盛るとその逆に減る。
連続な密度場なので個数ではなく体積のほうが素直で、掘った量と盛れる量がそのまま釣り合う。
木材・石炭・皮・骨と、道具・武器・防具は**個数**で数える。
`Inventory` は内部で小数を持ち、表示と支払いのときだけ切り捨てる。

### クラフト（`items/items.ts`）

マスに並べる方式ではなく、**材料が揃っていれば押すだけ**。`E` で開く画面の右側に
レシピが並び、作れるものだけが押せる。道具・防具は `unique` なので 2 個目は作れない。

材料はすべて世界から手に入るもので閉じている（掘る・伐る・倒す・交換する）ことを
テストで確かめている。岩を掘るとまれに石炭が出て、これが松明とガラスの材料になる。

### MOB（`mobs/`）

| | 動き | 落とすもの |
| --- | --- | --- |
| 亡霊 | 夜に湧いて追いかけてくる。朝になると消える | 骨 |
| 鹿 | 近づくと逃げる | 皮 |
| 村人 | 村の広場から離れずに歩く。`F` で交換 | — |

**経路探索は持っていない。** 地形が連続な密度場なので、「行きたい向きへ加速して、
めり込んだら勾配方向へ押し出す」だけで坂も段差も歩ける
（プレイヤーとまったく同じ `密度 / |勾配|` の押し出し）。
壁に当たって止まったら向きを変える、それだけで十分に動いて見える。

見た目は地形と同じく外部アセットを使わず、箱と球を組み立てて作る（`mobs/mobs.ts`）。

### 戦闘

左クリックの対象は **MOB > 木 > 地形** の順に手前のものが選ばれる。
攻撃力は手に持っているもの（素手 1 / 石の剣 4 / 骨の剣 8）、
防具は**持っているだけで効く**（いちばん良いものが選ばれる）。
体力が 0 になると最寄りの村で目を覚ます。**持ち物は失わない** —
セーブが編集差分だけなので、死に戻りを重くしても得るものが無いため。

### 建材と松明

素材を 4 → 7 に増やした。頂点属性は `matw`（草・土・岩・砂）と
`matw2`（板・レンガ・ガラス）の 2 つの vec4 で、シェーダで 7 つを混ぜる。

**ガラスは本当に透ける。** 地形メッシュは 1 つだが、`surfaceNets` がガラスの三角形を
インデックスの後ろにまとめ、`geometry.groups` で切り出して透過マテリアルを張る。

松明は光源。three のライト数はシェーダのコンパイル単位に効くので、
`PointLight` は 6 個だけ作って**近い順に使い回す**（見た目の松明は全部出る）。

## なぜボクセルに見えないのか

ワールドの実体はブロックの配列ではなく、**連続な密度場** `density(x, y, z)` である
（`> 0` が固体）。これを **Surface Nets** で等値面として取り出す。

| 課題 | 手法 |
| --- | --- |
| 段差の排除 | 符号が混在するセルごとに 1 頂点を置き、位置をエッジ交差点の平均にする（`surfaceNets.ts`） |
| 滑らかな陰影 | 法線は密度場の勾配（中央差分）を三線形補間して求める。面法線を使わないのでファセットが出ない |
| チャンクの継ぎ目 | 各チャンクは格子 `[-2, 32+2]` をサンプルし、セル `[-1, 32)` を生成する。隣接チャンクは同じ密度関数から同じコーナー値を得るので、境界の頂点は数値的に完全一致する |
| UV が存在しない | ワールド座標の**三面投影**でテクスチャを貼る。テクスチャは起動時に CPU で生成するタイリングノイズで、外部アセットは不要（`proceduralTextures.ts` / `TerrainMaterial.ts`） |
| 素材の境界 | 頂点属性を素材 ID ではなく **4 成分の重み** `matw` にして GPU 補間させる |
| 編集の形 | ブラシを符号付き距離場 `s`（外が正）として合成する。設置 `d = max(d, -s)` / 掘削 `d = min(d, s)`。何度掛けても発散せず、常にブラシの形そのままになる（`edits.ts`） |
| 掘った縁の切れ端 | 掘ったあとにブラシ球の近傍だけを掃除する。下の「切れ端が残らない理由」を参照 |

## ブラシの形

ブラシは符号付き距離場なので、球でも直方体でも同じ合成式で扱える（`BrushShape`）。

### 直方体ブラシ — なぜ「完全に鋭い」直方体が出せるのか

Surface Nets はセルごとの頂点をエッジ交差点の**平均**に置くので、ふつうは鋭い稜が
1 セルぶん面取りされる。ところが**箱の面を格子平面にちょうど乗せる**と話が変わる。

面の上の格子点は密度がちょうど 0 になる。等値面の判定は `> 0` なのでこれは空気に入り、
隣の固体との交差点は補間パラメータ `t = 0` または `1`、つまり**その格子点そのもの**になる。
交差点がすべて箱の表面に乗るので、平均も箱の表面に乗る。角のセルでも同じで、
3 本の交差点がすべて角の 1 点に集まるため、**頂点は箱の角に厳密に一致する**。

そのため `snapBoxCenter()` で箱の中心を丸め、一辺は整数 m に固定している。
実測（`brushShapes.test.ts`）:

| | 抽出した面と箱の表面のずれ |
| --- | --- |
| 格子に合わせた箱 | **0.000 m**（完全に鋭い） |
| 半セルずらした箱 | 0.33 m |
| 任意の位置の箱 | 0.49 m |

設置側だけは `SURFACE_BIAS = 1e-4` を足して、表面の格子点を固体側に入れている。
掘削 (`min`) では表面が空気になるのが正しいが、設置 (`max`) では表面まで埋まってほしいためで、
これが無いと角が 2/3 格子ぶん欠ける。

**残る限界は陰影のほう。** 法線は密度場の勾配から作るので、稜の両側 1 格子（= 1 m）だけ
法線が滑らかに繋がってしまう。形は厳密に鋭いが、稜のハイライトは 1 m ぶんぼやける。
面の内側の頂点（8 m の箱で全体の 44%）は法線が完全に軸に一致する。
これを消すには稜を検出して法線を割る必要があり、地形全体を滑らかに見せる仕組みと
競合するのでやっていない。

### 土砂 — 落ちて安息角の山になる／掘れば崩れる

`MATERIAL_INFO` の `repose`（安息角）が 0 でない素材（土 38°・砂 32°）は粒状として扱う。
岩と草は 0 なので今までどおり形のまま固まる（橋や壁を作れなくなると困るため）。

崩す処理 `settleLoose()` は **ブラシと無関係な単独の関数**で、入力は範囲だけ。
何が緩いかは密度場と素材 ID から自分で読む。おかげで盛った瞬間だけでなく、
**あとから山の下を掘ったときにも同じ処理で崩れる**。

「どの土砂がまだ緩いか」のために新しい状態は持っていない。格子点ごとの素材 ID は
もともと編集差分として IndexedDB に保存されている（`storage.ts`）ので、
**プレイヤーが置いた土・砂は既にタグ付き**になっている。

#### 何が緩いか

| | 緩いか | 深さ |
| --- | --- | --- |
| プレイヤーが置いた土・砂 | 常に緩い | 制限なし |
| 自然地形で、地表素材が土・砂寄りの柱 | 緩い | 地表から `NATURAL_SKIN` (2.5 m) まで、かつ編集点から `NATURAL_RADIUS` (3 m) まで |
| 草・岩、およびその下の自然地形 | 緩くない | — |

自然地形が緩いのは**掘った周辺だけ**。ワールド全体は今までどおり安定していて、
掘っていない砂丘が勝手に崩れたりはしない。自然素材の判定は `surfaceSample()` の
重みで行うが、**重みを混ぜて安息角を作ってはいけない**（草地の傾斜が浅くなって
逆に崩れやすくなる）。土＋砂が 0.6 を超えたときだけ、優勢な方の安息角を使う。

この定義から自然に出る挙動:
- 浅いトンネル（天井 2.5 m 未満）は崩落し、深いトンネルは保つ
- 砂地・土の斜面を掘るとすり鉢状に崩れる
- 草地・岩場を掘っても崩れない

#### 柱ごとの高さ場に置き換えて解く

密度場を直接崩すと格子の解像度でしか動かせずボクセル臭くなるので、柱ごとに解く。

1. 上端の格子点を探す。ブラシより上に地面が続いていれば遡る
   （山の下を掘ったとき、山の頂上はブラシより上にある）。
   急斜面では大半の柱がこれに当たるので、1 マスずつではなく**指数的に跳ばしてから二分探索**する
2. そこから下へ「緩い」格子点が続く範囲を切り出す
3. その下が空気なら、さらに下の地面まで落とす（`PILE_FALL` = 48 m まで）
4. 隣との高さ差が `tan(安息角)` を超える分だけ隣へ流す。
   流せるのは緩い分だけなので、**元の地形は削れない**
5. 動いた柱だけ書き戻す。非緩固体には union しかしないので地形と岩は削れない

**平衡状態では 1 件も書き込まない**ので冪等で、掘るたびに編集差分が膨らむこともない。

崩す処理を走らせるのは、緩い土砂に触ったとき・粒状の素材を置いたとき・
**土や砂の自然地形を掘ったとき**だけ。判定は読み込み済みの素材 ID を数えるのと
`surfaceSample()` 1 回で済むので、岩場や草地の掘削は今までどおりの負荷で終わる。

限界:
- 半径は 3.5 m で頭打ち。どのみち崩れて広がるので、それ以上は計算量だけ増える
- 崩れるのは編集した瞬間だけ。連鎖はブラシ + `PILE_SPREAD` (6 m) の中で 1 回解いて終わり
- 48 m より下へは落ちない

### ならしブラシ

密度場そのものをラプラシアン平滑化する。

```
d ← d + w ⋅ λ ⋅ (隣接 6 点の平均 − d)      （λ = 0.5、2 回）
```

密度に対するこの操作は、等値面に対しては**平均曲率流**になる。つまり出っ張りは削れ、
へこみは埋まり、**平らな面と一定の傾斜は動かない**（一次関数のラプラシアンは 0 なので、
何度かけても書き込みが 1 件も発生しない — 回帰テストあり）。

`w` はブラシ中心で 1、縁で 0 になる `smoothstep` なので、ブラシの境界に段差が出ない。
体積の帰属が曖昧なので、掘削・設置と違って**手持ち量は増減させない**。

## 切れ端が残らない理由

掘ると、ブラシ球と地表がほぼ接するあたりに**面で 1 個しか繋がっていない固体の格子点**が
残る。Surface Nets は密度が正の格子点があるところにしか面を作らないので、これが
「宙に浮いた小さな塊」として描画されてしまう。実測すると 1 回の掘削で 10 → 36 に増えていた。

そこで `edits.ts` はブラシを合成したあと、**ブラシ球から 1 格子ぶんの範囲だけ**を掃除する。

1. **とげを削る** — 面で隣り合う固体が 1 個以下の格子点を空にする（2 回）。
   板状の壁は面隣接が 4 個あるので削られない。幅 1 格子の触手だけが消える。
2. **小塊を消す** — 6 近傍で連結成分を取り、ブラシの外へ繋がっていない 8 格子点以下の
   塊を空にする。斜めでしか繋がっていない塊も「見た目には切り離された切れ端」なので消す側に倒す。

対象をブラシ球の近傍に限っているので、ボタンを押しっぱなしにしても穴がそれ以上
広がることはない（回帰テストあり）。掃除は密度を読んだあとの局所バッファ上で行うため、
密度の評価回数は増えていない。

## 地形の作り方

`world/density.ts` の `baseHeight()` が 2D の高度場を、`density()` が 3D の肉付けを担当する。

- **ドメインワープ**した大陸ノイズを実効レンジで正規化し、陸と海がほぼ半々になるようにする
- **山岳マスク × 尾根ノイズ²** で鋭い山を作り、二次尾根で断崖と段丘を重ねる
- **バイオーム**は気温・湿度の 2 つの低周波ノイズ。丘の振幅、砂丘、素材、木の種類と密度、
  シェーダの草の色と雪線がすべてこれで変わる
- **川**は尾根ノイズのゼロ交差線（`1 - |noise| / 幅`）に沿って地形を海面下まで引き下げる。
  **湖**は低地の窪みを同様に海面下へ沈める。海面は一枚の平面なので、`y < 0` を彫れば自動的に水が入る
- **オーバーハングと洞窟**は地表付近と地中だけで 3D ノイズを効かせる（`density()`）

## 木と村

**木**（`world/vegetation.ts`）は Worker がメッシュ化した直後に、**上向きの頂点**をそのまま
足場として選ぶ。4.6 m 格子のセルごとに 1 本までとし、置くかどうか・種類・大きさは
セル座標のハッシュだけで決まるので、再メッシュしても同じ場所に戻る。
地面を掘って頂点が消えれば木も消える。描画は種類ごとの `InstancedMesh`、
幹は垂直円柱としてプレイヤーの当たり判定に使う。

**伐採**は木全体を覆う垂直円柱にレイを当てて判定し、地形より手前にある木を
左クリックで切り倒す。`InstancedMesh` からは末尾と入れ替えて `count` を減らすことで
即座に消え、同時に**セルキーを伐採済み集合に記録**する。この集合は Worker に渡されて
`scatterTrees` がそのセルを飛ばすので、再メッシュやリロードのあとも生えてこない。

**村**（`world/village.ts`）は 420 m グリッドのセルごとに決定論的に生成する。
セル内で数か所試し、海の中・山の上・起伏が大きすぎる場所を避けて敷地を決める。
敷地は密度場の側で平坦化する — `height()` が地形を敷地高さへブレンドし、
同時に 3D のオーバーハングと洞窟も抑えるので、建物が乗る本当に平らな地面になる。
建物の壁は `buildingBoxes()` が返す軸平行ボックスで、**描画も当たり判定も同じ配列**を使う。
ドアの位置だけ壁を分割して開口にしてあるので、見た目どおりに出入りできる。

## 移動と当たり判定

カプセルの軸上の数点をサンプルし、`密度 / |勾配|` を符号付き距離の近似として
勾配方向へ押し出す（`player/Player.ts`）。地形が滑らかなので、ブロック地形のような
「段差を登る」特別処理は要らない。

接地判定は押し出しの副作用ではなく**足元への独立したプローブ**で行う。これが重要で、
- 接地中は重力を溜めない → 押し出しベクトルの水平成分で斜面をずり落ちない
- 入力が無いときは強い制動＋停止しきい値をかける → 坂で立ち止まれる
- 下り坂では純粋な鉛直補正で地面へ吸着させる → 滑らずに地形へ追従する

密度は**メインスレッドに一切保持しない**。衝突判定やレイキャストが必要とする点で
解析的に評価し、編集差分を上書きして三線形補間する（`World.sample`）。

## テスト

`npm test`（vitest）は等値面抽出と村レイアウトの正しさを検証する。

- 球の密度場から抽出した全頂点が半径の上に乗る（誤差 < 0.12 — ボクセル表現なら 0.5 前後になる）
- 頂点法線が解析的な外向き法線と一致する（内積 > 0.985）
- 全三角形の巻き順が外向き（裏面が出ない）
- **隣接チャンクを独立にメッシュ化しても境界の頂点が完全一致する**（継ぎ目が出ない証明）
- 球ブラシが冪等で、掘る↔盛るを往復しても密度が発散しない
- **掘った縁にとげが残らず、浮いた小塊も消える**。板状の壁は削られず、押しっぱなしでも穴が広がらない
- **実際の地形を掘っても切れ端が増えない**（球・直方体・ならしの 3 通り、`digQuality.test.ts`）
- **格子に合わせた直方体ブラシの面・稜・角が厳密に出る**（ずれ < 1e-6 m）。格子からずらすと
  面取りされることも対で検証している（`brushShapes.test.ts`）
- **ならしブラシが凸凹を落とし、平らな斜面は動かさず、ブラシの外を書き換えない**
- **土砂が安息角より急な斜面を作らず、球より横に広がり、20 m 上から落としても地面まで落ち、
  元の地形を削らない。落ち着いたあとは 1 件も書き込まない**（`pile.test.ts`）
- **積んだ山の麓を掘ると崩れてきて、掘った穴に流れ込む**。岩は崩れないし落ちない
- **崖の足元を掘ると上が崩れるが、動くのは表土だけ**。草地・岩場はそもそも崩れない
- 村が決定論的に生成され、建物どうしが重ならず、**ドアの位置に開口がある**
- **クラフトは材料が揃ったときだけ通り、ちょうど 1 足りないと通らない**。道具は 2 個目を作れない
- **すべてのレシピの材料が、世界から手に入るものだけで閉じている**
- 持ち物の保存と読み込みが往復し、壊れたデータを読んでも落ちない
- **MOB が重力で地面に落ちて止まり、敵だけが殴ってきて、動物は逃げる**。
  倒したときだけドロップし、奈落に落ちただけでは落とさない（`mobs.test.ts`）
- **クラフトした建材が `matw2` に乗り、ガラスの三角形だけが後ろにまとまる**

`npm run test:e2e`（Playwright）は実際にブラウザで動かす。

- 視界内チャンクが全てメッシュ化され、描画が継続し、掘削がワールドに反映される
- `B` でブラシが巡回し、直方体ブラシが一辺表示になり、地形が削れる
- ならしブラシは地形を変えるが手持ちを増減させない
- `T` で時刻が巡回し、固定した時刻は進まない
- 盛った土がブラシ半径の外まで崩れて広がり、元の地面を下げない
- 積んだ山を掘ると、ブラシの届かない外側まで崩れてくる
- `E` で持ち物が開き、材料が揃ったレシピだけ作れる（`gameplay.spec.ts`）
- **クラフトしたレンガを置くと、実際にメッシュの頂点までその素材が届く**
  （ワーカーが素材 ID を落としていないことの確認）
- 松明を置いて掘ると回収できる。置けないものを持っていると盛れない
- 殴られると体力が減り、防具があると軽くなり、0 で復帰する
- MOB を倒すと素材を落とし、村人とは交換できる
- **WASD がカメラの向きどおりに動く**（前後・左右の取り違えの回帰テスト）
- **入力を離すと止まり、斜面でも 0.2 m 以上滑らない**（滑りの回帰テスト）
- 村が生成され、壁の当たり判定を持ち、木が生えている
- シードを指定しなければ `SAMPLE_SEED` になり、同じシードなら同じ地形になる
- `V` キーで最寄りの村へワープする
- **木を切ると消え、リロードしても戻らない**
- **手持ち 0 では盛れず、掘ると貯まり、盛ると減る**

ヘッドレス環境は SwiftShader（CPU ラスタライザ）なので数 fps しか出ない。
フレームレートの測定ではなくフリーズ検出が目的で、物理も 1 フレームあたりの
サブステップ上限で頭打ちになるため、移動テストは距離ではなく向きを見ている。
